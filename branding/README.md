# BARO · 晴雨

- Brand and app display name: **BARO**
- Chinese name: **晴雨**
- Repository/package slug: **baro**
- Tagline: **Half data, half sky.**

Today's weather on the left, a living pixel sky on the right.

Bilingual, built for the big screen. Data by Open-Meteo.

中文：左边是今日天气，右边是流动的像素天空。中文或英文界面，为大屏而生。

## App icon studies

Current direction: **S1a is the provisional cloud choice**, with no sun or lettering. The user retained **G1** from [the graphite/navy background studies](icons/v9/README.md). The [current darker G1 studies](icons/v10/README.md) lower its brightest values and narrow its tonal range while keeping the native 4096px cloud foreground unchanged. Final background selection remains open.

The [previous six-way comparison](icons/v8/README.md) retains A2, B1, S1 and S3 beside S1a/S3a. Earlier [volume](icons/v3/README.md), [size/background](icons/v4/README.md) and [cloud-only](icons/v2/README.md) studies remain available. The user requires project-native artwork, with no image-generation output or decorative ripple overlays. Candidate assets are separate from the live Android resource tree.
