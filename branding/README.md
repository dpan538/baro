# BARO · 晴雨

- Brand and app display name: **BARO**
- Chinese name: **晴雨**
- Repository/package slug: **baro**
- Tagline: **Half data, half sky.**

Today's weather on the left, a living pixel sky on the right.

Bilingual, built for the big screen. Data by Open-Meteo.

中文：左边是今日天气，右边是流动的像素天空。中文或英文界面，为大屏而生。

## App icon studies

Current direction: a single refined cloud on a neutral dark rounded-square tile, with no sun. The user chose **02 / 圆润** from [the volume studies](icons/v3/README.md), retained **A2** and **B1** from [the size/background candidates](icons/v4/README.md), then selected the direction of **S1** and **S3** from [the 4096px detail studies](icons/v7/README.md). The [current six-way comparison](icons/v8/README.md) retains all four and adds S1a/S3a, continuing the cloud's own shallow front volume. The user requires project-native artwork, with no image-generation output or decorative ripple overlays. [The earlier cloud-only comparison](icons/v2/README.md) is retained as reference. Candidate assets are separate from the live Android resource tree.
