## 原生像素画的迭代约束

- 同首页使用 WebGL、`resolvePixelGrid`、解析轮廓、体积法线、分层光色和有序抖动。未复用首页整幅场景。
- 观测页基础档从 96 提高至 192 列，细杆至少占可见像素；小窗格和百叶片简化。首页默认仍为 96 列。
- 精细档每轴使用原生尺寸两倍采样，至多 1536 列且受双轴 GPU 边界约束，增加百叶、桁架、屋顶接缝、窗框、设备线缆、雪深杆和冰凌等局部细节。
- 基础档云恢复早期的轮廓与柔和垂直明暗；精细档用更细的解析云体。两档不是同一张图片缩放。
- 岛屿站为平顶浅色气象台；雷暴站为低矮海岸监测堡；雪山为木屋；晨雾为宽窗研究舱；雾林为高脚塔。温室、落日台也采用正视图，无抽象侧面。
- 房屋和基座不随画面整体平移；风速仪、风机、雨雪、星光、水面与雾使用独立慢节奏。
- 曾试验的 ImageGen 素材和图片采样代码已全部撤回，不在项目资源或提交中。

## 实际验收

本记录只填写已完成的检查；数量、边界检查不能替代审美判断。预览图为实际浏览器截图：`images/observation-scenes-basic.jpg`、`images/observation-scenes-fine.jpg`、`images/observation-commute.jpg`、`images/observation-purpose-photo.jpg`。

- 十一环境 × 中英文，1440×960：29 模块，字段唯一所属，模块与分组无边界溢出。
- 十一环境 × 精细/基础两档：均为 `instrument-webgl2`；实际对照精细网格为 1323×660（上一版 662×330），基础网格为 192×96。每幅画面已目视核对，截图保留。
- 1600×900 十二目的逐项切换：模块未裁切。600×900 英文/华氏/英里、1064×960 中文竖向、1600×900 中文检查通过。
- 实际修复并复查：云层第三行、气温范围条、月相底部、竖屏 CIN 换行，以及高窗口倒计时字号随高度膨胀造成的裁切。
- 1630×1193 实际窗口：通勤与晚霞目的复查无裁切；指针拖动从通勤切到骑行并将主指标改为阵风；返回首页后重新进入，原生观测渲染恢复。
- `npm run check` 与 `npm run gallery` 通过。新增累计降水恒定 4 mm/h × 2h = 8 mm 检查；观测页自定义基础网格及 GPU 上限检查通过。
- 多 iframe CUA 观察记录过无来源的 MutationObserver 错误；项目源码未使用该接口。没有据此声称对照页全日志无错误，GPU 场景均实际绘出。
