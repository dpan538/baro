# Xiaomi Pad 9 Pro Max 显示约束

本文件是当前设备目标的统一入口；较早的 3456×2304、2304×3456 是历史参考画幅，不能继续写成该型号的物理分辨率。

## 设备与 CSS 尺寸

- 设备目标：3408×2272 物理像素，横屏 3:2；竖屏为 2272×3408，2:3。来源：[小米社区发布资料](https://new.c.mi.com/ua/post/106256)。[小米参数入口](https://www.mi.com/prod/xiaomi-pad-9-pro-max/specs)的抓取结果未包含参数正文，不能把其空正文当作数值证据。
- 唯一代码定义：`dist/tablet-profile.js`。开发预览 `dist/tablet-preview.html` 和画廊构建共用这个定义；设备预览支持横竖屏、页面和语言切换。
- 2× 是验收参考密度，对应 1704×1136 / 1136×1704 CSS 像素，不是已测得的安卓 WebView DPR。另检查 2.5× 参考密度和两种方向的完整物理尺寸边界。
- 实际网页始终响应可用 viewport；物理尺寸不能直接写成网页的固定 CSS 宽高。预览只对整个 iframe 做等比缩放，不压伸组件或字体。

## 铺满与状态栏

- 观测页 `.sky-page` 固定覆盖 viewport，`.instrument-console` 使用扣除边缘和系统安全区后的全部宽高。删除旧的 683px 内容高度上限和垂直居中留白。
- 比例核对对象是整个面板（包含目的拨轮），不是只占 7/9 宽的左侧仪器组。不能据后者的宽高把整个页面误改成 1:2。
- 两页在横屏默认预留 24 CSS px 的安卓状态栏空间，并与 `env(safe-area-inset-top)` 取较大值；窄边框另算。没有绘制假状态栏图标。
- 宿主若已经把 WebView 放在系统状态栏下方，应在根元素提供 `--android-statusbar-height:0px`；若提供实际状态栏高度，须先换算成 CSS px。同一入口由两页使用，避免二次扣除系统栏。
- 竖屏保留系统 safe-area inset。浏览器预留只能验证几何，不能替代真实安卓 inset、帧率或功耗测试。本轮未构建 APK。

## 字体、颜色与组件

- 两页共享 MiSans / Inter / Roboto Mono 的标题、数字和元数据角色；同级仪器标题在一个画幅下使用同一字号，26px 或紧凑配置的 24px，字重 450。用户指定的英文 LCL 标题是唯一 95% 适配例外。读数使用 400；主指标与紧凑数值条保留各自的数值层级。
- 目标参考画幅的辅助文字、图表刻度和顶部小数字至少 16px；较小逻辑视口保留 14px 下限。环境解读正文为 22px，紧凑配置为 20px。
- 白底采用首页的 `--paper: #fcfcf8`，中性色辅助面更亮；暗色组为中性炭灰 `#30302d`，底框 `#1e1e1c`、拨盘 `#20201e`；辅助浅底也去除绿调，保持亮色读数与细线。旧仪器字体文件及许可保留，但不再作为当前字体角色。
- 横屏四栏按可用高度分配图形空间；2:3 竖屏仍是 96 条细分行轨。底部微环境与解读等高，横屏 140px、竖屏 156px；紧凑横屏为 132px。高度随可读文字需求分配，不再靠缩小字体塞入旧行高。
- 环境解读显式使用 `minmax(0,1fr)` 内容列、左对齐和 12px 内边距。短文字也占满内容宽度，避免网格列按文本宽度居中。读数与图形使用明确的 12–16px 间距；紧凑配置保留 8px。
- 气温轨道使用中性深灰渐变与亮色标记；轨道两端对珊瑚底的对比分别约 5.19:1 / 3.48:1。指示标记保留深色边缘。
- 风速卡的主读数、表盘和底部两列元数据各有明确轨道；拨盘保留 2/9 栏宽，通过更大的半径、文字、一条细弧和少量刻度扩大视觉体量。
- 月盘为纯二维正圆及明暗块面，椭圆分界按近似月龄计算；无渐变、浮雕、表面纹理或生成图像。Bortle 仍未测。
- 环境解读按目的组织。储存建议解释物品表面温度、结露与受潮；居家建议解释衣物和潮湿物品的蒸发与风雨影响；夜空/摄影/远眺解释云、光线、镜片和远景；通勤与户外停留才使用体感说明。没有测得器材温度，不能断言器材已经结露。

## 小逻辑窗口回退

最新要求覆盖旧的滚动回退：两页均固定一屏，第二页不允许上下拖动。原生观测页按实测视口宽度映射到横屏 1704、竖屏 1136 的设计坐标，画布、插画和触摸区域使用相同比例；保留每个主图至少占卡片高度 85% 的要求。320 与 400 dpi 下都需实际验证横竖屏、十二用途和中英文，不能通过缩小单个图形或增加屏外内容满足边界。参考密度仍不等于小米真机 DPR。设置列表保留独立的纵向滚动。

## 验收入口

运行 `npm run dev` 后打开 `/tablet-preview.html`。同时运行 `npm run check` 和 `npm run gallery`；实际界面检查包括状态栏后的底边铺满、同级标题计算字号、模块边界、解读文本完整性、月盘形状及中英文切换。截图证据与完成数量记录在组件审计和实施状态中。

最新视觉约束：纯白模块间的短线增至原长三倍（最多 168px、66% 栏宽），向上移 3px，标题起点不动。月盘亮部为纯二维浅暖白。主阵风方向盘占右侧完整高度，主月盘跨读数与说明两行；两者保留 16px 数字/图形间距。设备预览默认播放首页天气动画，显式 `motion=off` 可暂停；精细/基础两档整套循环均为 45 秒。

## 设置触摸约束

首页竖屏以 2:3 设备参考重排为上下各半的信息与动画区。信息区采用独立的较小字号和内容行高；竖屏隐藏云量及日出／日落插图，保留时间、事件标题和次日说明，与天气图标及描述一起放在温度右侧。指标区使用明确的上下内边距，动画前保留 2cqw 的底部内边距。横屏继续显示完整云量及插图。此约束只针对今日天气首页，观测页布局不变。

设置使用完整长列表；顶部三项只负责定位，保留触摸滑动、快捷入口和键盘滚动。主设置控件至少 56 CSS px 高；首页齿轮和设置关闭键共用位置与尺寸。更新卡片在右侧画面上方，最多 560px 宽，操作按钮至少 56px，关闭触摸区域 64×64px，但叉号图形不大于设置叉号。关闭设置立即关闭卡片并取消检查。详细交互规则见 [SETTINGS-INTERACTION.md](SETTINGS-INTERACTION.md)。


## 原生发布前覆盖：两页整屏与切换（2026-10-24）

最新用户反馈覆盖原生第二页白色状态栏预留：天气页和观测页都隐藏常驻系统栏，两页共用完整、固定的滑动视口。观测仪器从自身深色边框开始，不留白色顶条；需要查看系统信息时可用系统边缘手势短暂唤出。仍尊重实际 cutout、caption 与输入法边界。冻结网页的历史截图和状态栏规则继续保留，不能用它们恢复原生白条。

语言和用途点选采用 320ms 线性交叉淡化，旧内容与新内容衔接。用途拨轮和天空不被用途内容快照遮挡，连续拖动保持即时跟随；拖动内容轻过渡 220ms、拨轮收尾 220ms，设置选中标记 320ms、开关 300ms。快速连点以最后选择为准；关闭、后台、旋转和系统关闭动画时清除临时快照。图片只来自即时原生控件绘制，完成后释放，不是产品插画资源。
