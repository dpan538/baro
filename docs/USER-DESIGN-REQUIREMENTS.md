## 本次追加与覆盖（2026-10-23）

- 左侧改成四栏；拨轮宽度由 1/3 改为 2/9，顶部主读数由 4/9 改为 2/9。像素画继续独立。
- 至少新增九项信息：当前新增十五模块（含后续环境解读），覆盖光影倒计时、固定月相/升落组、分层风/PWV/零度层/CAPE/土壤水分/辐射/地表热差/短时降水，以及 CIN/LCL 与目的相关微环境参数。
- 能见度仅保留名称、数字、单位。云层不占大高度，改为三行覆盖率，空出一格用于湿球温度、VPD 或温变。
- 阵风与来向元数据字号至少增加 20%，标题顶部留白增加。修掉概率图被压扁的 `100%` SVG 字号；负零按零显示。
- 顶部 CIN/LCL 与 CAPE 上下耦合，共享一组外框。辅助信息不逐个使用四个圆角。
- 核心/次核心仍用红/黄区分，但最新反馈要求克制：辅助组件改为中性组底色，只通过标题墨色区分主次，删除全部侧边色条，主组件使用低饱和珊瑚底色，不能铺满红黄大框。
- 高空风矢量放大并按速度比例比较；箭头表示漂向，文字保留气象来向。直漫射使用放大的占比弧线；夜间零值不伪造可视化。
- CIN 与 LCL 按环境互换位置；湿球/VPD/温变按目的替换。数据依旧去重，建议上限依旧三条、每条二十字。


## 最新追加：密度、对比与原生像素画

- 每个组件单独收紧，不允许等分高度把简单读数拉成空框；四栏内部独立分配高度。
- 气温、体感、PM2.5、零度层改成短条；短时降水压低，下面新增两小时累计量细条。两者分别为 mm/h 与 mm，不重复同一量。
- 删除全部侧栏/侧边色条。辅助组件以中性色面组织，标题墨色表示主次。
- 湿度环必须在珊瑚底和浅色底都清楚；云量填充、太阳高度标记加强对比。
- 月相图放大到宽屏 128px，值、相位、升落贴合排列，取消伸展空白。
- 左上角必须使用首页相同的原生 WebGL 像素技术。**不得使用 ImageGen 素材或图片贴图替代。** 生成图试验已经撤回，未纳入项目资源。
- 精细档适度增加建筑、设备与地表细节；基础档从 96 列提高到 192 列，首页仍保留 96 列默认值。
- 低精度云保留早期轮廓与柔和的垂直明暗；高低两档采用各自的细节处理。
- 所有建筑改为正视图，去掉温室、落日台等斜侧面。建筑要有不同轮廓：平顶岛屿气象台、海岸监测堡、雪山木屋、山谷研究舱、高脚瞭望塔、温室和开放落日台。
- 结构重点是可读的屋顶、窗框、立柱、基座、台阶与接地关系，不能靠抽象透视制造体积。

逐组件处理与实际检查见 [组件视觉核对](COMPONENT-VISUAL-AUDIT.md)。

## 过程记录：图形密度与 3.4K 2:3 屏幕（14:50）
