# 用户设计要求与迭代核对

此文件记录本对话中的产品设计约束。新反馈覆盖旧方案时以最新明确要求为准；完成状态必须由源码检查或实际浏览器观察支持，不能仅凭组件数量或测试通过宣称视觉符合。

| O16 | 中文或英文单独显示；保留温度/风速单位设置 | 双语/单位核对；不改首页设置结构 |

## 已被新反馈替代的方案

- 早期第二页的导出卡、独立时间滑块、额外目的按钮、顶部工具栏已被取消。
- “齿轮/链条”只表达信息联动，不能画成实体装饰。
- 不能把参考图的波形、棱锥、环形流线当作无关数据的装饰；本轮删除这些旧图形。
- 十四个同样大小的大框不等于十四个有效组件。新骨架必须同时满足去重、紧凑、字号和数据映射。

## 早期提出的数据候选与状态

- 已展示：太阳高度/方位与光照时段、三层云量、湿度/露点、能见度、风速/阵风/来向、气压与三小时变化、示例 PM2.5、近似月相、参考色温和规则霞光指数。气象趋势均为示例，太阳几何为近似计算。
- 尚未接入实际数据：月升月落、光害/Bortle、PWV、太阳辐射、实测 UV 曲线、分高度风切变、DEM 遮挡/海拔、历史罕见度、真实霞光持续时间、镜头焦段/滤镜/EV 与精确结露时刻。这些仍为候选能力，不用假值填满组件。
- 最初要求的时间滑块与导出卡已被后来明确反馈取消，不能以“补全功能”为由恢复。

## 本轮验收记录

- 十一种环境 × 中英文，在 1440×960 画幅检查十四模块、唯一时段、字段去重与溢出；通过。
- 在雷暴场景逐一切换十二目的，确认每个字段只有一个所属模块、露点组件仅一个、时段仅一个；通过。
- 600×900 英文/华氏/英里，以及 1064×960 中文竖向画幅检查十四模块与溢出；通过。跨日时段在同一入口显示 `+1`。
- 实际大屏读数：视窗约 32.4% 宽，主读数约 43.4% 宽；相对湿度标题约 27.5px，数字字距为正（约 1.3px），均与上一版实际界面核对。
- 1600×900 更矮窗口复查时发现风/气压/露点辅助信息裁切，改为紧凑两行布局与合并读数后重查通过；曲线用满宽度，刻度保持可读。
- 拨轮按实际容器比例重新计算文字弧线；紧凑和竖向画幅中，当前标签与蓝色指示点均留在视野内。实际拖动从通勤切换至骑行，主指标变为阵风；返回首页再打开第二页，确认画面独立且渲染恢复。
- 新增 264 组数据归属与图形映射检查，覆盖露点合并、主/辅组件互斥、风向、气压变化、云量比例、能见度刻度、湿度、色温与方位映射。
