# Distribution status

APK packaging and publication are paused. Use the [web preview](PREVIEW.md) to review the weather screen. There is no public BARO APK release at this stage.

Existing Android sources and local historical packages are retained for later work. Generated packages, SDKs, local caches and signing material do not enter Git. The historical application ID is `studio.sundown.weather`; any future release must make a deliberate signing and upgrade decision.
